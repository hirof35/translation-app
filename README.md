Advanced English Wordbook (Python / Tkinter)
英単語の検索、意味の自動取得、日本語訳の自動生成、そして自分専用の単語帳への保存を一貫して行うGUIデスクトップアプリケーションです。

概要
本ツールは、学習者が読書や作業中に遭遇した未知の英単語を即座に記録し、後で復習できるように設計されています。Free Dictionary API と googletrans を組み合わせることで、精度の高い英定義と日本語訳を同時に提供します。

主な機能とエンジニアリングのポイント
マルチスレッド処理 (Non-blocking GUI):
API通信や翻訳処理を threading モジュールによるバックグラウンド処理で実行。ネットワークの遅延が発生してもGUIがフリーズ（応答なし）せず、快適な操作感を維持します。

自動翻訳・定義取得機能:
単語を入力するだけで、英語の定義（英英辞典的アプローチ）と日本語訳を同時に取得。多角的な視点から単語の理解を深めます。

スマートなデータ永続化:
軽量な JSON 形式で単語データを管理。登録日時、英定義、和訳を構造化して保存し、次回起動時もシームレスに履歴を参照可能です。

ユーザビリティの最適化:

Enterキー対応: 入力から検索までキーボードのみで完結。

スタック表示: 履歴画面では最新の登録単語が一番上に表示されるようソート。

入力オートフォーカス: 起動時に入力欄へ自動でフォーカス。

スクリーンショット (イメージ)
メイン画面：単語入力と検索結果のプレビュー

履歴画面：これまでに保存した単語のリスト表示

依存ライブラリ
本ツールの実行には以下のライブラリが必要です。

Bash
pip install requests googletrans==4.0.0-rc1
※ googletrans は最新の安定版である 4.0.0-rc1 の使用を推奨します。

操作方法
検索: 中央の入力欄に英単語を入力し、Enter または 検索＆保存 ボタンを押します。

結果: 検索が完了すると、下のResultエリアに定義と訳が表示され、自動的にJSONファイルへ保存されます。

履歴: 履歴を表示 ボタンを押すと、別ウィンドウでこれまでの学習記録を閲覧できます。

システム構成
GUI: Tkinter (Standard Library)

API: Free Dictionary API

Translation: googletrans (Google Translate API)

Storage: JSON (wordbook_jp.json)
